## 🚀 Cómo Usar Este Sistema

### Para Crear una Nueva Skill
1. Lee `INICIO-RAPIDO.md`
2. Copia `skill-template/` a `mi-skill-nombre/`
3. Sigue `GUIA-PERSONALIZAR.md`
4. Personaliza archivos
5. Commit y push a Git

### Para Entender la Estructura
- Lee `ESTRUCTURA.md` para explicación completa
- Analiza `skill-template/` como ejemplo
- Mira `movie-finder/` como skill real

### Para Personalizar
- Sigue `GUIA-PERSONALIZAR.md` paso a paso
- Actualiza `marketplace.json` con tus datos
- Personaliza `plugin.config.json` si es necesario
